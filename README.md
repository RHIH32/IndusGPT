# 🤖 IndusGPT - The Ultimate Desi AI Assistant 🇮🇳

IndusGPT is not just another boring AI chatbot. It is a highly intelligent, culturally localized, and heavily customized Indian AI assistant. Built to be expressive, sarcastic, and genuinely helpful, IndusGPT brings a unique "desi" flavor to the AI world. 

Whether you want to generate code, create images, get roasted by your AI, or talk to it in Bhojpuri — IndusGPT does it all!

## ✨ Key Features & USPs

*   🗣️ **True Multilingual Support:** Chats fluently in Hinglish, Hindi (Devanagari), Bhojpuri, Marathi, Gujarati, Bengali, Tamil, Telugu, Urdu, and more.
*   🎭 **Crazy AI Personas (Vibe Mode):** Switch the AI's personality with a single click! 
    *   🔥 *Friendly Roast:* Gets your work done but roasts you first.
    *   👓 *Babu Rao Mode:* Classic Hera Pheri style responses.
    *   💪 *Bhoi Mode:* Swag-filled attitude.
    *   ✍️ *Shayari Mode:* Starts every technical answer with a poetic verse.
*   💸 **Kanjoos Mode:** Turn this on, and the AI will scold you with typical middle-class logic if you ask about buying expensive gadgets (like iPhones or Gaming Laptops) before suggesting cheaper alternatives.
*   📸 **Viral Meme Card Generator:** Turn any funny AI response into a high-quality, beautifully gradient-styled Image Card with one click. Instantly shareable to WhatsApp Status and Instagram Stories!
*   🎙️ **Smart Voice Assistant:** Integrated Speech-to-Text (STT) and Text-to-Speech (TTS) configured explicitly for Indian English (`en-IN`) and Pure Hindi (`hi-IN`) accents. No more robotic foreign accents!
*   🎨 **Image Generation & File Reading:** Generate AI images directly in the chat or upload documents/images for deep analysis.
*   💻 **Developer Pro-Tools:** Fully supports Markdown formatting, Markdown Tables, `Highlight.js` for code blocks (with 1-click Copy buttons), and `Mermaid.js` for generating flowcharts and diagrams directly in the chat!
*   📱 **Android WebView Ready:** Seamlessly bridges with native Android code (`window.Android`) for smooth image downloads and native voice recognition.

## 🛠️ Tech Stack

*   **Frontend:** HTML5, Vanilla JavaScript, Tailwind CSS (for beautiful glass-morphism UI).
*   **Authentication:** Firebase Auth (Google Sign-in, Email/Password, Guest Login).
*   **Backend / AI:** Custom Node.js/Express API connected to Gemini AI.
*   **Libraries:** `html2canvas` (for Meme Generator), `marked.js` (Markdown), `highlight.js` (Syntax), `jspdf` (PDF Export).

## 💡 Designed For The Future
IndusGPT utilizes a sliding sidebar, smart auto-scroll, dynamic typing effects, and a glass-morphism floating input bar (Apple style) for a premium user experience on both mobile and desktop screens.
